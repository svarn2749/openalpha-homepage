# openalpha-homepage

Static homepage for [openalpha.co.nz](https://openalpha.co.nz), hosted on GitHub Pages.

- `index.html` – the page (coming-soon page)
- `styles.css` – styling
- `CNAME` – tells GitHub Pages which custom domain to serve

Preview locally: `python3 -m http.server 8000` then open http://localhost:8000
